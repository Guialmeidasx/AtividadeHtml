# 👨‍💻 Meu Site Pessoal

## 📌 Sobre o projeto

Este projeto consiste na criação de um **site pessoal**, desenvolvido para apresentar um pouco sobre minha trajetória, meus interesses e meus hobbies.

O site é composto por três páginas principais:

- 🏠 Início
- 👤 Sobre mim
- 🎮 Hobbies

O projeto foi desenvolvido utilizando HTML5 e CSS3, com foco na organização do conteúdo, estilização e responsividade.

## 🎯 Objetivo

O objetivo deste projeto é colocar em prática os conhecimentos adquiridos em desenvolvimento web, principalmente na utilização de:

- HTML;
- CSS;
- Estrutura de páginas;
- Links entre páginas;
- Imagens;
- Menus de navegação;
- Responsividade;
- Organização de arquivos.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
